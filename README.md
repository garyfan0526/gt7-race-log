## 兩種模式

- **本機模式**（⚙ 設定沒填後端網址）：資料存在瀏覽器裡，截圖只能手動填。適合試用。
- **雲端模式**：資料存 Google Sheet「GT7 賽事紀錄」、截圖存 Drive「GT7 截圖」、Gemini 自動辨識；手機和電腦共用同一份資料。

## 記錄方式

1. **📷 截圖**：可以一次選多張。AI 辨識後會跳出表單讓你核對，按儲存才會寫入。電腦版也可以直接把圖拖進視窗。
2. **✍ 手動**：不經過 AI，直接填表（可附加截圖）。Gemini 額度用完時用這個。
3. **⏳ 待確認**：額度用完時，截圖會先排隊，後端每小時自動重試辨識，辨識好再點進去確認。

同一張截圖會用指紋擋掉，不會記兩次。

## 部署步驟

### 1. 後端（Apps Script）
1. 到 script.google.com 建立新專案，把 `Code.gs` 貼進去；在專案設定勾選「顯示 appsscript.json」，貼上 `appsscript.json`。
2. 專案設定 → 指令碼屬性：
   - `GEMINI_API_KEY`：在 Google AI Studio 建立的金鑰
   - `PASSCODE`：自訂通關密碼
   - （可選）`GEMINI_MODELS`：預設 `gemini-flash-latest,gemini-flash-lite-latest`，依序嘗試，額度滿了就換下一個
3. 編輯器選 `setup` 按執行並授權。這一步會建立 Sheet、Drive 資料夾，並設定每小時的排隊重試。
4. 部署 → 新增部署作業 → 網頁應用程式，執行身分選「我」，存取權選「所有人」，然後複製 `/exec` 網址。
5. 改了 `Code.gs` 之後，要用「管理部署作業 → 編輯 → 新版本」重新部署，網址不會變。

### 2. 前端（GitHub Pages）
把這個資料夾（`apps-script/` 可以不放）推到 GitHub repo，開啟 Pages。

### 3. 第一次開網頁
到 ⚙ 設定填入：遊戲內玩家名稱、後端網址、通關密碼。每台裝置要各填一次。

iPhone：在 Safari 按「分享 → 加入主畫面」，就會像 App 一樣全螢幕開啟。PS App 的截圖先存到「照片」，再從網頁的 📷 選取。

## 注意事項
- Drive 截圖設成「知道連結的人可檢視」，網頁縮圖才能直接顯示。遊戲截圖沒有個資。
- 地圖底圖使用公開的 world-atlas 資料，賽道點與標籤是自己畫的，沒有使用遊戲的畫面或 logo。
