## 畫面
0. **首頁**：左半世界賽道（競技場圖＋方格旗）、右半車庫（車庫圖＋車庫圖示），附各自的進度；點了才跳轉。任何畫面點左上角 GT 回首頁。手機改上下分割。
1. **世界賽道**：三個地區轉盤，顯示「拿過第一的地點 / 總數」，外圈刻度依完成度變金色；下方是最近紀錄。
2. **地區地圖**：點轉盤進入，可切子區域。賽道卡顯示最佳名次徽章和「🏆 拿過第一的賽事數 / 總賽事數」，紅點代表還沒跑過。
   - 手機（地圖區寬 < 900 或高 < 560）：一行精簡卡片，放不下的名稱先隱藏（紅點仍可點，放大後出現）；直放時「◀＋子區域」併到頂列按鈕那一排。電腦版不受影響。
3. **賽道面板**：像遊戲一樣一場賽事一張卡片（PP / 圈數 / 配置 / 限制 / 最佳成績 / 共 N 筆）。點卡片看這場**全部紀錄**，每筆可單獨編輯、刪除；「＋ 記錄這場」會自動帶入賽事資料。對不到賽事清單的紀錄放在「其他紀錄」。

4. **車庫**：上方切換「我的戰績」（只列跑過的車）／「全部車款 580 台」（官方全部車款，依廠牌 A–Z，中文名廠牌排最後；沒跑過的灰色「未出賽」，可看規格並「＋ 用這台記一筆」）。左邊依廠牌列出車（文字徽章＝廠牌名＋代表色＋國旗，不用官方 logo），可依類別篩選、排序、搜尋；點車看規格、勝場、全部戰績，點一筆跳到該賽道的賽事。對不到官方清單的車名集中在「清單外」，可用「整理名稱」一次對應。
   - 每筆紀錄只存一次（賽道＋賽事＋車），地圖和車庫是同一份資料的兩個角度，改／刪同步。
   - 表單車名必須從官方清單選（打部分名稱有候選、遊戲簡稱自動換成全名）；遊戲改版的新車可勾「清單沒有這台」照原樣存。

頂列按鈕是「儀表板警示燈」風格：自繪線條圖示＋琥珀色 LED 發光字（Orbitron 字體），主要按鈕 SHOT 綠燈；強調色統一為琥珀。配色由 `<body data-theme="amber">` 控制，`style.css` 另備有 ice／red／green 三組配色（Gary 選琥珀、不開放切換）。

介面配色和版面參考遊戲，但地圖、轉盤、圖示都是自己畫的；左上角 GT 是 Kanit 字體排的文字，沒有使用遊戲或官網的圖片和 logo。

## 記錄方式
1. **📷 截圖**：可以一次選多張。AI 辨識（含賽道、配置、賽事、名次、車、成績）後跳出表單讓你核對，按儲存才寫入。電腦版也可以直接拖曳圖片。
2. **✍ 手動**：不經過 AI，直接填表（可附加截圖）。選賽事會自動帶入配置、PP 上限、圈數。Gemini 額度用完時用這個。
3. **⏳ 待確認**：額度用完時，截圖先排隊，後端每小時自動重試辨識，辨識好再點進去確認。

同一張截圖會用指紋擋掉，不會記兩次。刪除紀錄時，截圖會一起丟進雲端硬碟垃圾桶（30 天內可還原）。

## 從零部署（備查）
1. script.google.com 建專案，貼上 `Code.gs`、`appsscript.json`；專案設定 → 指令碼屬性加 `GEMINI_API_KEY`、`PASSCODE`（可選 `GEMINI_MODELS`，預設 `gemini-2.5-flash,gemini-flash-lite-latest`）。
2. 執行 `setup` 並授權：建立 Sheet、Drive 資料夾、每小時重試排程。
3. 部署 → 網頁應用程式，執行身分「我」、存取權「所有人」，把 `/exec` 網址填到 `app.js` 的 `DEFAULT_API_URL`。
4. 前端推到 GitHub 開 Pages。每台裝置第一次開網頁時，在 ⚙ 設定填玩家名稱和通關密碼。
